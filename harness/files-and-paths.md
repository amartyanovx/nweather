# Файлы и пути

Техническая инструкция: читай перед правками, поиском и чтением файлов. Общие ограничения — `AGENTS.md`, терминал —
`harness/terminal.md`.

## Файлы

- Правки и чтение файлов проекта — файловыми инструментами агента, а не терминалом: терминалу — прогоны проверок и команд
  проекта, точечное форматирование и разведка командами (`harness/terminal.md`)
- Существующие файлы — точечные изменения штатным инструментом редактирования, связанные правки — одной группой. Полная
  перезапись — только для нового файла или осознанной замены
- Никаких временных файлов в проекте: промежуточные файлы — только в системном temp; вывод не перенаправляй внутрь
  репозитория
- Временные файлы и задания reviewer создавай инструментом записи по абсолютному пути системного temp фактического
  окружения, а не записью через терминал

## Пути

- Пути — в формате фактической ОС; не смешивай форматы разных окружений
- Файлы проекта адресуй от корня проекта: относительный путь в инструментах разрешается от корня; после смены каталога
  внутри скрипта — абсолютный путь
- Пути с пробелами и специальными символами квотируй по правилам окружения

## Поиск и чтение

- Перед поиском файлов изучи структуру проекта: если корень и нужная папка уже видны в контексте, листинг повторно не
  запрашивай
- Файл известен — читай его. Неизвестен — ищи по символу или строке, сузив путь и тип файла; ноль результатов — сними
  фильтр, расширь область
- Место правки известно — читай релевантные фрагменты; связи неясны — расширяй чтение по необходимости. Небольшой файл
  (сотни строк) не дроби: перед правкой должен быть виден точный текст изменяемого фрагмента
- Не перечитывай неизменившийся файл из контекста. После своих правок, внешних изменений или сжатия контекста —
  перечитай нужный фрагмент
- Целиком не читай lock-файлы, generated, снапшоты тестов, крупные фикстуры и `node_modules` — кроме задач про них
  самих. Нужен факт (версия пакета, наличие строки) — точечный поиск, а не чтение. В `node_modules` читай только точечно
  по известному пути: поиск по нему ограничен настройками игнорирования агента, а документация стека лежит там же
  (`AGENTS.md`, nextjs-блок)
