# Memory Bank — индекс

Открывать первым. Здесь только маршрутизация: что читать под задачу. Факты — в коде и конфигах, решения — в документах.

## Документы

| Файл                   | Только то, чего нет в коде                             | Бюджет     |
| :--------------------- | :----------------------------------------------------- | :--------- |
| projectbrief.md        | Зачем проект, границы, инварианты, UX-правила          | ≤ 45 строк |
| techContext.md         | Контракт API, неочевидные настройки, ловушки окружения | ≤ 55 строк |
| systemPatterns.md      | Решения и причины, поток данных, ловушки БД            | ≤ 60 строк |
| local/activeContext.md | Снимок текущей работы вне git (правила — ниже)         | ≤ 25 строк |
| defects.md             | Дефекты и долги, которых нет в коде                    | ≤ 20 строк |

Всего ≤ 15 000 символов (`wc -m memory-bank/*.md`), `index.md` ≤ 65 строк. Бюджет превышен — не дописывай текст, а
удаляй дубли: то, что выводится из кода и конфигов, в документах не хранится, только ссылка.

## Маршрутизация

| Задача                        | Читать                                                           |
| :---------------------------- | :--------------------------------------------------------------- |
| Новая функциональность        | projectbrief → решения в systemPatterns                          |
| Исправление ошибки            | поток данных в systemPatterns, дефекты и долги — в defects       |
| Рефакторинг                   | systemPatterns; techContext — если конфиги или зависимости       |
| Конфигурация и инфраструктура | techContext                                                      |
| Продолжение работы            | `local/activeContext.md` (шапка совпала с веткой/HEAD) → defects |

Не читай весь Memory Bank. Один документ на задачу; второй — только если на него есть ссылка.

## Источники истины (не переписывать сюда)

| Факт                                     | Где смотреть                                                                      |
| :--------------------------------------- | :-------------------------------------------------------------------------------- |
| Версии, скрипты, пороги, globs, таймауты | `package.json`, `jest.config.ts`, `.stryker.config.js`, `playwright.config.ts`    |
| Схема БД, подключение, seed              | `src/lib/schema.ts`, `src/lib/db.ts`, `scripts/seed.ts`                           |
| Состав файлов, покрытие, оценка мутантов | `src/`, `__tests__/`, `tests/`; вывод `npm test`, `npm run mutate`, `npm run e2e` |
| Правила кода, команды, лимиты, формат    | `AGENTS.md`                                                                       |

## Правила ведения

- Один факт — в одном файле, в остальных ссылка («см. `techContext.md`»); запись = утверждение + путь к источнику, без
  кода, логов и пересказа `schema.ts` или конфигов.
- Документируй намерение, причину, отвергнутые варианты, ограничения и контракты — то, чего не выводится из кода;
  хронология — `git log`, решения — `systemPatterns.md`, открытые долги — `defects.md`; состояние проекта в документах не
  хранится.
- Не документируй пороги, версии и числа покрытия.
- `local/activeContext.md` — снимок работы, не журнал: очищается только при старте новой сессии или смене ветки, в
  остальных случаях не удаляется; по ходу работы актуализируется под текущую задачу.
- Шапка `[hh:mm][dd-MM-yy] · ветка · HEAD · файлы из git status`, секции Цель/Шаги/Дальше/Дефекты; шапка не совпала с
  `git rev-parse` (другая ветка или HEAD) — файл черновик, состояние проекта — код и `git log`.
- Дефект или долг — строка `D-NN` в `defects.md` с путём к коду; ID не перенумеровывается, закрытый переезжает в
  «Закрытые», а не удаляется.
- Запись в `defects.md` — без дат: время и автор — `git log`; метка `[hh:mm][dd-MM-yy]` — только в шапке чекпоинта.
- Документ противоречит коду — исправь документ в той же задаче; документ противоречит документу — дефект ревью.
- Новый документ — строка в таблицах выше и бюджет; удалённый — его строки убрать.
- Изменил структуру Memory Bank — обнови `AGENTS.md`, раздел «Memory Bank».

## Проверка перед сдачей

- Дублей нет: `grep -rnoE '200 мс|resetWeatherCache|#c2185b|WORD_SEPARATORS' memory-bank/*.md | grep -v index.md |
cut -d: -f3 | sort | uniq -d` — пусто: каждый факт живёт в одном файле, `index.md` исключён (в нём сами шаблоны).
- Бюджеты: `wc -m` ≤ 15 000, `wc -l` по таблице; `npx prettier --check memory-bank/*.md` зелёный.
- Пути и имена документов существуют (`ls memory-bank/`, исключение — `AGENTS.md`), чекпоинт отражает текущую сессию;
  удалённый документ не упомянут в правилах и `AGENTS.md`.
- Шапка чекпоинта совпадает с `git rev-parse` (ветка и HEAD); новая сессия или ветка — файл переписан заново.
