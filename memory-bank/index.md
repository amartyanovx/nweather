# Memory Bank — Карта знаний проекта

В этой директории хранится информация о проекте, необходимая AI-агентам для понимания его устройства, принятия решений и выполнения задач.
Используй этот файл для определения того, какие документы необходимо изучить перед началом работы.

## Карта знаний

| Файл              | Содержание                                                                      | Когда читать                                                |
| :---------------- | :------------------------------------------------------------------------------ | :---------------------------------------------------------- |
| projectbrief.md   | Назначение проекта, цели, границы и основные требования                         | При знакомстве с проектом, планировании новых функций       |
| productContext.md | Предметная область, роли пользователей, сценарии использования и бизнес-правила | При разработке функциональности и работе с бизнес-логикой   |
| techContext.md    | Технологический стек, инфраструктура, окружения и инструменты                   | При работе с конфигурацией, зависимостями и инфраструктурой |
| systemPatterns.md | Архитектурные паттерны, соглашения и принятые технические решения               | При выборе подходов к реализации и проектировании           |
| activeContext.md  | Текущий фокус проекта, выполняемые задачи и последние изменения                 | При продолжении незавершённой работы                        |
| progress.md       | Выполненные задачи, оставшаяся работа и известные ограничения                   | При планировании и продолжении разработки                   |

**Инструменты форматирования:** информация о Prettier в techContext.md

## Стратегия загрузки контекста

Выбирай документы исходя из характера текущей задачи. Ниже приведены типовые сочетания документов для разных задач.

### Разработка новой функциональности

projectbrief.md
productContext.md
Соответствующие разделы systemPatterns.md

### Исправление ошибки

Соответствующие разделы systemPatterns.md
activeContext.md, если ошибка связана с текущей работой

### Рефакторинг

Соответствующие разделы systemPatterns.md
techContext.md, если затрагиваются инструменты или зависимости

### Инфраструктура и конфигурация

techContext.md

### Продолжение незавершённой работы

activeContext.md
Соответствующие разделы progress.md
Дополнительные документы в зависимости от задачи

## Правила поддержки документации

Поддерживай этот индекс в соответствии с фактическим содержимым Memory Bank.
Не копируй в memory-bank код и логи: указывай пути к файлам.
Добавляй новые документы в карту знаний после их создания.
Обновляй соответствующие документы при изменении знаний о проекте.
Удаляй ссылки на удалённые или устаревшие документы.
Не дублируй в индексе подробную информацию из других документов.
Сохраняй описания документов краткими и ориентированными на поиск нужного контекста.
Если структура Memory Bank меняется, обновляй соответствующие инструкции в AGENTS.md.
