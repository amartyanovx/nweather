# Memory Bank — индекс

Открывать первым. Здесь только маршрутизация: что читать под задачу. Факты — в коде и конфигах, решения — в документах.

## Документы

| Файл                   | Только то, чего нет в коде                             |
| :--------------------- | :----------------------------------------------------- |
| projectbrief.md        | Зачем проект, границы, инварианты, UX-правила          |
| techContext.md         | Контракт API, неочевидные настройки, ловушки окружения |
| systemPatterns.md      | Решения и причины, поток данных, ловушки БД            |
| local/activeContext.md | Снимок текущей работы вне git                          |
| defects.md             | Дефекты и долги, которых нет в коде                    |

Правила — отдельно и только по необходимости: `maintenance.md` (ведение банка, бюджеты, проверка перед сдачей),
`activeContextRules.md` (чекпоинт `local/activeContext.md`). В обычной задаче их не читай; новые правила ведения
добавляй туда, а не в `index.md` и `AGENTS.md`.

## Маршрутизация

| Задача                        | Читать                                                           |
| :---------------------------- | :--------------------------------------------------------------- |
| Новая функциональность        | projectbrief → решения в systemPatterns                          |
| Исправление ошибки            | поток данных в systemPatterns, дефекты и долги — в defects       |
| Рефакторинг                   | systemPatterns; techContext — если конфиги или зависимости       |
| Конфигурация и инфраструктура | techContext                                                      |
| Продолжение работы            | `local/activeContext.md` (шапка совпала с веткой/HEAD) → defects |

Не читай весь Memory Bank. Один документ на задачу, второй — только по ссылке; бюджет загрузки — ≤ 3 000 токенов,
комплексная задача — до 6 000.

## Источники истины (не переписывать сюда)

| Факт                                     | Где смотреть                                                                      |
| :--------------------------------------- | :-------------------------------------------------------------------------------- |
| Версии, скрипты, пороги, globs, таймауты | `package.json`, `jest.config.ts`, `.stryker.config.js`, `playwright.config.ts`    |
| Схема БД, подключение, seed              | `src/lib/schema.ts`, `src/lib/db.ts`, `scripts/seed.ts`                           |

| Правила кода, команды, лимиты, формат    | `AGENTS.md`                                                                       |
