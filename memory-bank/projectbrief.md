# Project Brief: nweather

## Назначение

Демонстрационное приложение погоды на Next.js App Router и TypeScript (версии — `package.json`): один полный сценарий —
поиск города → недельный прогноз → переключение дней, Server Components по умолчанию, минимальный клиентский остров.

## Данные

- Города реальные, 100 записей: фикстура `src/data/cities.json`, источник истины — таблица `cities` в SQLite
  (`src/lib/schema.ts`). Других таблиц нет.
- Прогноза нет ни в БД, ни у провайдера: он генерируется на каждый запрос и кэшируется в памяти процесса.
- «Сегодня» и границы недели считает сервер в таймзоне города (`src/lib/weather/dates.ts`).

## Границы

- В скоупе: поиск города с подсказками, недельный прогноз, табы по дням, загрузка и ошибки с повтором.
- Вне скоупа: авторизация, настройки, геолокация, реальный провайдер, адаптив сверх простой центрированной вёрстки.

## Инварианты

- Строгая типизация без `any`; Server Components по умолчанию.
- `ForecastDay` (`src/types/weather.ts`): `minTempC < maxTempC`, `precipitationMm ≥ 0`, `humidityPct` в `[0, 100]`,
  `pressureHpa` в `[950, 1050]`, `windSpeedMs` в `[0, 25]`; осадки только у `rain`/`snow`/`thunderstorm`.
- Отсутствующая метрика не подменяется нулём: в интерфейсе показывается `—`.

## Сценарий и UX-правила

- Экран: «Nweather» → поле «Город» с подсказками → табы дней → карточка дня (условие, температуры, осадки, давление,
  влажность, ветер, время суток).
- Поиск: ввод фильтруется, совпадение с двух символов по `name`/`nameEn`, дебаунс 200 мс, ≤ 8 подсказок, «Ничего не
  найдено» без совпадений — правила в `src/lib/cityQuery.ts`.
- До выбора города прогноза нет; ввод после выбора или крестик сбрасывают город и прогноз. Активный день — `isToday` из
  ответа сервера, смена города сбрасывает выбранный день.
- Загрузка — skeleton-заглушки, ошибка — текст с кнопкой «Повторить» (`mutate` из SWR).
- Минимализм: одна колонка, числа моноширинным; светлая тема по умолчанию (голубая `#b7cddf`), тёмная — Monokai, слайдер
  переключения в правом углу хедера, выбор сохраняется; контраст текста ≥ 4.5:1 (`src/app/globals.css`).

## Точки входа

Стек — `package.json`, пояснения — `techContext.md`; API — `src/app/api/{cities,forecast}/route.ts`; хуки — `src/hooks/`;
поиск и форматирование — `src/lib/cityQuery.ts`, `src/lib/forecastFormat.ts`; генерация и кэш — `src/lib/weather/`;
границы Server/Client Components — `systemPatterns.md`.
