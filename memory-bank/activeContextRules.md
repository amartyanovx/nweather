# Active Context — правила чекпоинта

Читай перед записью чекпоинта — в конце каждой задачи; правила банка — `maintenance.md`.

`local/activeContext.md` — снимок всей текущей сессии вне git (`memory-bank/local/` в `.gitignore`), не журнал между
сессиями и не источник истины: состояние проекта — код и `git log`, долги — `defects.md`.

- Обновляется после каждой задачи, перед итоговым ответом, сохраняя всю сессию: цель, выполненные задачи с результатом,
  текущую задачу, следующий шаг и дефекты; пропуск — задача не сдана
- Внутри сессии дополняется — результаты задач не теряются; новая сессия или смена ветки — файл обнуляется и пишется
  заново
- Шапка `[hh:mm][dd-MM-yy] · ветка · HEAD · файлы из git status`, секции Цель/Шаги/Дальше/Дефекты; шапка не совпала с
  `git rev-parse` — черновик, состояние проекта — код и `git log`
- Без дублей и копий кода: пути, решения и следующий шаг, а не содержимое файлов; бюджет — 800 токенов; превышение —
  сжать, а не терять значимое
