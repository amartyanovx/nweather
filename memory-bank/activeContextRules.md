# Active Context — правила чекпоинта

Читай при сбое или сжатии контекста в сессии (основное назначение) и перед записью чекпоинта — в конце каждой задачи;
правила банка — `maintenance.md`.

`local/activeContext.md` — снимок всей текущей сессии вне git (`memory-bank/local/` в `.gitignore`), не для передачи между
сессиями и не источник истины: состояние проекта — код и `git log`, статусы дефектов и долга — Jira (пока не подключено).

- Обновляется после каждой задачи, перед итоговым ответом, сохраняя всю сессию: цель, выполненные задачи с результатом,
  текущую задачу, следующий шаг и открытые вопросы; пропуск — задача не сдана
- Внутри сессии дополняется — результаты задач не теряются; новая сессия или смена ветки — файл обнуляется и пишется
  заново
- Шапка `[hh:mm][dd-MM-yy] · ветка · HEAD · файлы из git status`, секции
  Цель/Шаги/Дальше/Открытые вопросы; шапка не совпала с `git rev-parse` — черновик, состояние проекта — код и `git log`
- Без дублей и копий кода: пути, решения и следующий шаг, а не содержимое файлов; бюджет — 800 токенов; превышение —
  сжать, а не терять значимое
