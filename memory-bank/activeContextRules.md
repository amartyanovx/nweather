# Active Context — правила чекпоинта

Читай, только когда пишешь `memory-bank/local/activeContext.md`. Маршрутизация — `index.md`, правила банка —
`maintenance.md`.

`local/activeContext.md` — личный снимок работы вне git (каталог `memory-bank/local/` в `.gitignore`), не журнал и не
источник истины: состояние проекта — код и `git log`, долги — `defects.md`.

- Очищается (переписывается заново) только при старте новой сессии или смене ветки; по ходу работы актуализируется под
  текущую задачу, а не удаляется и не растёт хронологией
- Шапка `[hh:mm][dd-MM-yy] · ветка · HEAD · файлы из git status`, дальше секции Цель/Шаги/Дальше/Дефекты; шапка не
  совпала с `git rev-parse` (другая ветка или HEAD) — файл черновик, состояние проекта — код и `git log`
- Без дублей и копий кода: пути, решения и следующий шаг, а не содержимое файлов; целевой бюджет — 800 токенов,
  превышение — повод сжать, а не терять значимое
