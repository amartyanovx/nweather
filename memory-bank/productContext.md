# Product Context: nweather

## Зачем этот проект существует?

nweather — демонстрационное приложение погоды, показывающее возможности Next.js 16 App Router в сочетании с TypeScript и SWR. Приложение предназначено для обучения и тестирования современных веб-технологий.

## Какую проблему решает?

Предоставляет простой и быстрый интерфейс для просмотра погодных данных по выбранным городам с удобным переключением дней недели через табы.

## Пользовательский опыт

1. Пользователь открывает приложение и видит заголовок "Погода"
2. Выпадает список городов (7 вымышленных локаций)
3. После выбора города отображается недельный прогноз погоды
4. Пользователь может переключаться между днями недели через интерактивные табы
5. Для каждого дня показываются: максимальная/минимальная температура, осадки, давление

## Ключевые фичи

- **Выбор города**: выпадающий список с 7 городами из таблицы `cities` (`dev.db`): Лунный Берег, Водяной Пик, Звёздный
  Край, Туманное Утро, Кристальный Хребет, Серебряный Путь, Бурный Город
- **Прогноз на неделю**: данные лежат в таблице `daily_weather` — по 7 записей на город (Понедельник–Воскресенье)
- **Интерактивные табы**: переключение дней с подсветкой активного таба
- **Состояния загрузки и ошибок**: индикатор `Загрузка...`, сообщения о неудачной загрузке и кнопка `Повторить`
  (повторный запрос через `mutate` из SWR)

## UX принципы

- Минимализм: простая центрированная верстка с максимальной шириной 960px
- Быстрый отклик: SWR кэширование предотвращает повторные запросы
- Понятная типографика: monospace шрифт для числовых данных погоды
