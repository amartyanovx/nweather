# Cline — совместимый слой

Единая точка входа и обязательные always-on правила — `AGENTS.md`: прочитай его перед работой. Здесь только механика
Cline, которая не дублирует правила. Файлы и терминал — `docs/files-and-paths.md` и `docs/terminal.md`: читай перед
работой с файлами и командами.

## Как запустить reviewer

- Reviewer — отдельная сессия Cline CLI в plan mode, без истории этой сессии. Из корня проекта:
  `cline -p -c . -t <секунды> "$(cat <файл с заданием>)" > <лог вне репо> 2>&1`; задание и лог — файлы системного temp
  (`docs/files-and-paths.md` §«Файлы»)
- В задании: «прочитай `.clinerules/reviewer.md` и работай по нему»; сценарий (план или реализация); требования;
  ограничения проекта; план либо снимок области изменений с базой; прогоны — команда, статус, где лог; запреты — правки
  файлов проекта, установка пакетов, миграции, seed, сборка, commit
- Read-only контроль держится на задании и дисциплине reviewer: plan mode ограничивает инструменты, а не среду; запреты и
  границы задаёт `.clinerules/reviewer.md`
- Для PR база — `git merge-base <целевая ветка> HEAD`; укажи способ получить diff и состав изменений (закоммиченные,
  staged, unstaged, новые файлы). Область неоднозначна — напиши это, а не подставляй предположение
- Вывод CLI читай целиком: вердикт и замечания — из полного текста, а не из последних строк; сохрани их в контекст задачи
- CLI недоступен или прогон не работает — независимого ревью нет: саморевью за него не выдавай и сообщи конкретное
  препятствие
