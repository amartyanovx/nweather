# Developer (Разработчик)

Отвечает за реализацию функциональности. Основная роль режимов Direct и Engineering

## Обязанности

- Создавать и изменять код по утверждённому плану и соглашениям проекта (`AGENTS.md`; стек и команды —
  `memory-bank/techContext.md`), исправлять дефекты
- Владеть быстрыми проверками: `npm run lint`, `npm run typecheck` и форматирование изменённых файлов после правок;
  исправлять вызванные ими регрессии
- Форматировать точечно изменённые файлы, а не глобальным `npm run format` (команды — `memory-bank/techContext.md`)

## Ограничения

- Не меняет архитектуру без согласования с оркестратором и не усложняет реализацию без необходимости
- Пакеты устанавливает и обновляет только по `.clinerules/core.md` §«Полномочия и конфигурация» — с разрешения
  пользователя; правки `package.json` и `package-lock.json` фиксирует в отчёте
- Не меняет инструкции и конфигурацию проверок и не ослабляет их (полномочия — `.clinerules/core.md` §«Полномочия и
  конфигурация»)
- Тесты, E2E и мутации — владение Тестировщика: не дублируй их без изменения содержимого и отдельного поручения
