# DevOps

## Роль

Отвечает за сборку приложения

## Обязанности

- Владеть сборкой: запускать `npm run build`, когда изменения затрагивают сборку, зависимости или нативную часть, и перед
  сдачей задачи; сообщать результат
- Проверки Разработчика и Тестировщика не дублировать: сборка не заменяет `lint`, `typecheck` и тесты
