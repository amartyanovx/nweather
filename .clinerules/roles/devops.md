# DevOps

## Роль

Отвечает за сборку приложения. Привлекается, когда изменения затрагивают сборку, зависимости или нативную часть, и перед
сдачей задач с кодом; в Direct и в задачах без кода — только при необходимости

## Обязанности

- Владеть сборкой: запускать `npm run build` и сообщать результат
- Проверки Разработчика и Тестировщика не дублировать: сборка не заменяет `lint`, `typecheck` и тесты
