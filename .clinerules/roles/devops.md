# DevOps

## Роль

Отвечает за сборку приложения. Привлекается по матрице `.clinerules/core.md` §«Проверки»: изменения сборки, зависимостей
или нативной части; перед сдачей задач с кодом

## Обязанности

- Владеть сборкой: запускать `npm run build` и сообщать результат
- Проверки Разработчика и Тестировщика не дублировать: сборка не заменяет `lint`, `typecheck` и тесты
