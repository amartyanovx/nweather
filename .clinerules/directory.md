# Рабочая директория

- Работай только внутри корня открытого проекта (он же корень VS Code): без `cd ..`, `ls /`, `~/.`.
  Глобальные утилиты вызывай без смены каталога.
- Для операций с файлами используй инструменты Cline/VS Code, а не терминал.
- Оболочка — Bash. `cmd` и PowerShell запрещены; если задача объективно требует их — остановись и спроси разрешение, не обходя правило другими оболочками.
- Перед поиском файлов изучи структуру workspace.
- Никаких `nul` и временных файлов в проекте: промежуточные файлы — только в системном temp, вывод не перенаправляй в файлы проекта и в корень репозитория (для тишины — `2>/dev/null`).
- Пути: в инструментах и командах — абсолютные, в отчётах и документации — относительные от корня.
- Перед завершением задачи гаси фоновые процессы (dev-сервер, `npm start`, E2E) через `kill` и не оставляй занятыми
  порты проекта.
